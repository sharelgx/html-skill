# Example Patterns

Use this file only when choosing a structure for an HTML artifact. Select one dominant pattern instead of mixing everything.

## Comparison Explorer

Use for technical approaches, vendors, designs, papers, or product options. Include side-by-side columns, tradeoff tags, risk levels, and a final recommendation lane.

Useful controls: filter by priority, toggle detail level, compare selected items, copy recommendation.

## Code Review Board

Use for PR reviews, refactor plans, migration diffs, or implementation audits. Lead with findings and risk, then show files, snippets, owner, status, and next action.

Useful controls: severity filter, file filter, expand/collapse details, copy review summary.

## Design System Sheet

Use for tokens, component states, variants, UI inventory, or visual QA. Show colors, type, spacing, states, and component examples in one scan-friendly page.

Useful controls: theme toggle, component tabs, state selector, contrast notes.

## Prototype Sandbox

Use for microinteractions, layouts, flows, or small app concepts. Make the prototype itself the main surface; keep notes secondary.

Useful controls: segmented modes, sliders, toggles, replay, reset, state switcher.

## Status Report

Use for weekly reports, project health, incident follow-ups, or operational summaries. Put state, progress, blockers, dates, and ownership in compact bands.

Useful controls: team/status filter, timeline scrub, expand blockers, export update.

## Flow Explainer

Use for architecture, API paths, pipelines, algorithms, or process education. Combine diagram, step list, callouts, and examples.

Useful controls: stepper, highlight path, show/hide code, FAQ accordion.

## Implementation Plan

Use for development docs, task breakdowns, roadmap slices, or handoff packets. Organize by milestones, data flow, files, risks, and test plan.

Useful controls: priority filter, phase tabs, dependency view, copy task list.

## Triage Board

Use for issue sorting, backlog reduction, topic grouping, or editorial planning. Make movement between categories the core interaction.

Useful controls: drag/drop cards, tag filter, reset, copy as Markdown/CSV.

## Feature Flag or Config Editor

Use when users need to safely inspect and edit structured settings. Show current state, validation warnings, diff output, and full export.

Useful controls: toggles, dependency warnings, diff preview, copy JSON.

## Prompt Tuner

Use for prompt templates, rubric tuning, instruction editing, or response style calibration. Put editable prompt on one side and live examples on the other.

Useful controls: editable text, sample selector, variable chips, reset, copy final prompt.
